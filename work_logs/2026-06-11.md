## 2. 当前已经完成的功能

### 2.1 FATE 已经接入 imputation

当前 FATE 的核心文件是：

```text
tabular/imputation/FATE.py
tabular/imputation/FATE_modules.py
docs/FATE_IMPUTATION_IMPLEMENTATION.md
tabular/test/unit_fate.py
tabular/test/test_fate.py
```

当前实现的 FATE 不是原论文完整的公平分类系统，而是：

```text
FATE-inspired mask-aware Transformer imputer
```

也就是把 FATE 论文里对 imputation 有用的部分抽出来，改造成 DataPrep 的缺失值补全算法。

保留的核心思想包括：

1. 缺失感知编码。
2. 数值 token 和 mask token 一起输入 Transformer。
3. 对缺失位置使用可学习的 missing embedding。
4. 第 0 层使用 missing-aware attention。
5. 后续层使用普通 Transformer block。
6. 用 reconstruction head 输出每个特征的预测值。
7. 训练时随机遮住 observed 位置，构造有答案的补全任务。
8. 预测时只替换原始 missing 位置，保留 observed 原始值。

FATE 的统一调用方式：

```python
from dataprep.tabular.imputation.FATE import FATE

model = FATE(
    batch_size=128,
    epoch=100,
    learning_rate=0.001,
    embedding_dim=32,
    depth=3,
    heads=4,
    mask_rate=0.2,
)

imputed_data = model.train_and_predict(data_missing, missing_mask)
metrics = model.estimate(ground_truth, imputed_data, missing_mask)
```

### 2.2 DARN 已经接入 imputation

当前 DARN 的核心文件是：

```text
tabular/imputation/DARN.py
tabular/imputation/DARN_modules.py
docs/DARN_IMPUTATION_IMPLEMENTATION.md
tabular/test/unit_darn.py
tabular/test/test_darn.py
```

当前实现的 DARN 也不是原论文完整的联邦学习系统，而是：

```text
DARN-inspired missing-aware Transformer imputer
```

也就是把 DARN 论文中对单机缺失值补全有用的部分抽出来，改造成 DataPrep 的 imputation 算法。

DARN 当前包含 4 个层次：

1. 基础层：和 FATE 类似的 missing-aware Transformer 结构，但默认使用 MAE reconstruction loss。
2. 渐进式自补全：`use_progressive=True` 时，周期性用模型预测值更新 missing 位置的 `fill_values`。
3. IPS 加权 attention：`use_ips=True` 时，对稀少 observed 特征提高 attention 权重。
4. 缺失分布预测头：`use_prob_head=True` 时，额外预测每个位置缺失的概率，并用 BCE loss 监督。

DARN 的统一调用方式：

```python
from dataprep.tabular.imputation.DARN import DARN

model = DARN(
    batch_size=128,
    epoch=100,
    learning_rate=0.001,
    embedding_dim=32,
    depth=3,
    heads=4,
    mask_rate=0.2,
    loss_type="mae",
    use_progressive=True,
    progressive_interval=10,
    gamma=0.1,
    use_ips=False,
    ips_method="simple",
    use_prob_head=False,
    beta=0.1,
)

imputed_data = model.train_and_predict(data_missing, missing_mask)
metrics = model.estimate(ground_truth, imputed_data, missing_mask)
```

## 4. Imputation 任务的输入和输出

### 4.1 输入 1：缺失数据 data_missing

`data_missing` 是一个带缺失值的数值表格。

在代码中通常是：

```python
data_missing = pd.read_csv("datasets/imputation/weather_raw.csv").values
```

形状是：

```text
[n_samples, n_features]
```

例如：

```text
[
  [30.0, NaN, 700.0],
  [40.0, 8000.0, NaN]
]
```

其中 `NaN` 表示这个位置缺失，需要算法补全。

### 4.2 输入 2：missing_mask

`missing_mask` 是和 `data_missing` 同 shape 的 0/1 矩阵。

语义是：

```text
1 = observed，原本有值
0 = missing，原本缺失
```

例如：

```text
[
  [1, 0, 1],
  [1, 1, 0]
]
```

表示：

1. 第一行第二列缺失。
2. 第二行第三列缺失。
3. 其他位置都是 observed。

在代码中通常是：

```python
missing_mask = pd.read_csv("datasets/imputation/weather_missing_mask.csv").values
```

### 4.3 输入 3：ground_truth

`ground_truth` 是完整的真实数据，只用于评估，不参与真实补全。

在代码中通常是：

```python
ground_truth = pd.read_csv("datasets/imputation/weather_ground_truth.csv").values
```

它的 shape 和 `data_missing`、`missing_mask` 一样：

```text
[n_samples, n_features]
```

### 4.4 输出：imputed_data

`imputed_data` 是算法补全后的完整表格。

要求：

1. shape 和输入 `data_missing` 一样。
2. 不应该包含 `NaN`。
3. 原本 observed 的位置保留原始值。
4. 原本 missing 的位置用模型预测值替换。

数学上可以写成：

```text
X_imputed = M * X_observed + (1 - M) * X_pred
```

其中：

```text
M = missing_mask
M = 1 的位置保留原始值
M = 0 的位置使用模型预测值
```

## 5. 评估指标：MSE / RMSE / MAE

老师提到的实验评估主要就是缺失值补全任务常用的误差指标。

当前项目里 `BaseImputer.estimate()` 会计算：

```text
MSE
RMSE
MAE
```

注意：这些指标只在原本 missing 的位置计算，也就是：

```text
missing_mask == 0
```

### 5.1 MSE

MSE 全称是 Mean Squared Error，均方误差。

公式：

```text
MSE = mean((真实值 - 补全值)^2)
```

特点：

1. 误差会被平方。
2. 大错误会被放大。
3. 数值越小越好。

### 5.2 RMSE

RMSE 全称是 Root Mean Squared Error，均方根误差。

公式：

```text
RMSE = sqrt(MSE)
```

特点：

1. 和原始数据单位一致。
2. 比 MSE 更容易解释。
3. 数值越小越好。

### 5.3 MAE

MAE 全称是 Mean Absolute Error，平均绝对误差。

公式：

```text
MAE = mean(abs(真实值 - 补全值))
```

特点：

1. 不会像 MSE 那样特别放大大误差。
2. 更直观，表示平均差多少。
3. 数值越小越好。

### 5.4 当前 UI 中的评估方式

在 DataPrep Console 的 Imputation 页面中，每次运行算法后，会对比：

```text
BayesianRidge
Random Forest
当前选择的算法，例如 FATE 或 DARN
```

表格和柱状图会展示：

```text
MSE
RMSE
MAE
```

所以之后做实验时，可以重点记录：

```text
FATE 的 MSE / RMSE / MAE
DARN 的 MSE / RMSE / MAE
GAIN 的 MSE / RMSE / MAE
VAEGAIN 的 MSE / RMSE / MAE
SCIS 的 MSE / RMSE / MAE
BayesianRidge 的 MSE / RMSE / MAE
Random Forest 的 MSE / RMSE / MAE
```

## 7. 目前需要重点阅读的代码

后续为了真正读懂 FATE / DARN 的 imputation 代码，建议按下面顺序学习。

### 7.1 先读统一接口

先读：

```text
tabular/imputation/base.py
```

重点看：

```python
train(data, missing_mask)
predict(data)
train_and_predict(data, missing_mask)
estimate(ground_truth, imputed_data, missing_mask)
```

需要理解：

1. 所有 imputation 算法都要继承 `BaseImputer`。
2. `train()` 只负责训练。
3. `predict()` 负责补全。
4. `train_and_predict()` 是先训练再预测。
5. `estimate()` 只在 missing 位置计算 MSE / RMSE / MAE。

### 7.2 再读一个已有模板：GAIN

建议读：

```text
tabular/imputation/GAIN.py
tabular/imputation/GAIN_modules.py
```

读 GAIN 的目的不是研究 GAN，而是理解项目模板：

1. 外层 `GAIN.py` 负责类封装、超参数、归一化、保存模型。
2. 内层 `GAIN_modules.py` 负责网络结构和训练循环。
3. 这个结构被 FATE / DARN 复用了。

### 7.3 读 FATE 的顺序

建议不要一开始直接读 `FATEImputerNet`，容易迷路。

推荐顺序：

```text
1. docs/FATE_IMPUTATION_IMPLEMENTATION.md
2. tabular/imputation/FATE.py
3. tabular/imputation/FATE_modules.py 的 train_fate_algorithm()
4. tabular/imputation/FATE_modules.py 的 sample_observed_mask()
5. tabular/imputation/FATE_modules.py 的 FATEImputerNet.forward()
6. tabular/imputation/FATE_modules.py 的 MissingAwareTransformerBlock
7. tabular/test/unit_fate.py
```

读 FATE 时要抓住一条主线：

```text
data_missing + missing_mask
    -> normalization
    -> random observed masking
    -> value token + mask token
    -> missing-aware Transformer
    -> reconstruction head
    -> x_hat
    -> 只替换原始 missing 位置
```

FATE 里最重要的变量：

```text
data            原始带 NaN 数据
missing_mask    1=observed, 0=missing
norm_data_x     归一化后且 NaN 临时填 0 的数据
train_mask      训练时模型能看到的位置
target_mask     训练时用来算 loss 的位置
x_input         喂给模型的输入
x_hat           模型预测出的完整表格
```

### 7.4 读 DARN 的顺序

推荐顺序：

```text
1. docs/DARN_IMPUTATION_IMPLEMENTATION.md
2. tabular/imputation/DARN.py
3. tabular/imputation/DARN_modules.py 的 train_darn_algorithm()
4. 先只看 loss_type='mae' 的基础版
5. 再看 use_progressive=True 的 fill_values 更新
6. 再看 compute_ips_simple() 和 compute_ips_logistic()
7. 再看 MissingAwareAttention 里 IPS 如何乘到 attention score 上
8. 最后看 use_prob_head=True 的 mask_prediction_head
9. tabular/test/unit_darn.py
```

读 DARN 时建议分层理解，不要一次性全读：

第一层：

```text
DARN = FATE 类似结构 + MAE loss
```

第二层：

```text
use_progressive=True
模型每隔一段 epoch 更新 missing 位置的 fill_values
然后用 fill_values 作为 pseudo-label 辅助训练
```

第三层：

```text
use_ips=True
根据每列或每格的观测概率计算 IPS
观测越稀少的特征，IPS 越大
attention 中该 key 的权重会被放大
```

第四层：

```text
use_prob_head=True
模型额外预测每个位置是否容易缺失
用 BCE loss 帮助模型学习缺失分布
```
